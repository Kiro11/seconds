Age in Seconds 

So what is this? A cute little project idea that calculates your exact age in seconds, minutes, hours and days from the moment you were born. Simple idea, but a fun one You can even add the exact hour you were born so the calculation is 100% accurate.

How was it built?

HTML + CSS + JS. Nothing fancy, pretty straightforward.

Did I use AI?

Honestly yeah, but not a lot. AI helped me with a couple of small things that genuinely got me stuck and I didn't know how to solve it . Other than that, I built the idea, the design and the code myself.
It also helped me with a few small CSS tweaks, like adjusting the font of a sentence and refining a couple of design details. Most of the project was done by me.
What you'll find in it
Enter your date of birth (and you can add the time too if you want it more precise)
It calculates exactly:
how many years
how many days
how many hours
how many minutes
and a live counter that ticks by the second right in front of you
